# Sistema Bancario - Java OOP
Proyecto académico para demostrar el uso de **Modificadores de Acceso** y **Encapsulamiento** en Java.

## Estructura de Paquetes
- `banco`: Contiene la lógica del negocio y el usuario.
- `externo`: Simula una entidad sin permisos de acceso a datos protegidos.
- `main`: Punto de entrada del programa.

## Conceptos Aplicados
- Encapsulamiento de saldos.
- Visibilidad `protected` vs `private`.
- Organización de código en paquetes.
